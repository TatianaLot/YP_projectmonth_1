# Проект Heart Risks (ML + приложение FastAPI)

## Цели исследования
Анализ факторов риска сердечного приступа и построение модели для предсказания риска сердечного приступа.

## Описание данных
Тренировочные данные из открытого источника, сгенерированные ИИ.

### Список переменных
- `id`
- Антропометрические параметры (вес, возраст, рост)
- Привычки (курение, качество сна и т.д.)
- Давление
- Наличие хронических заболеваний
- Биохимия крови
- Таргет - высокий или низкий риск поражения сердца

## Итоги обучения модели
Для модели выбрана модель RandomForest. Сама модель получилась не очень высокого качества. ROC-AUC максимально получился 80%, recall 84%, а precision будет на уровне 46%. Соответственно, 54% пациентов будут напрасно направлены на диагностику. Такое качество модели, на мой взгляд, обусловлено:

- Вопросами относительно репрезентативности и распределения ряда переменных в исходных данных.
- Самой природой изучаемого явления, потому что сердечный приступ является острым состоянием, которое иногда необъяснимо развивается внезапно (с одной стороны), но может и не наступить при наличии всех факторов риска (с другой стороны).

Анализ данных и обучение модели находится в ноутбуке `model_learn.ipynb`.

## Создание приложения и тестирование
Приложение использует классы `DataPreprocessor` и `HeartRiskPredictor`, созданные при обучении модели для предсказания heart risk. Классы и параметры обученных моделей импортируются с Google Drive.

### Эндпойнты приложения
- `/health` - проверка работоспособности приложения.
- `/predict` - предсказание на основании входных данных, передаваемых в виде словаря (тестирование на 1 пациенте). Аутпут в формате JSON.
- `/predict` - предсказание на основании входных данных, передаваемых в виде файла на Google Drive. Аутпут в формате JSON.

Приложение запускается на сервере Colab. Код приложения и тестирование работы приложения в ноутбуке `app_code_test.ipynb`.
